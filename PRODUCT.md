# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Keyboard designers moving between layout, PCB, component, and case work.

## Product Purpose

Provide a cohesive keyboard-design workbench without losing project context when changing tasks.

## Operating Context

The native workflow connects Design, PCB, Case, and Export. Part editing covers footprint geometry, pad mapping, and 3D models; board editing covers component placement and adjustment.

## Capabilities and Constraints

Preserve existing project data, generation, import, export, and editing capabilities. Bundled parts remain distinguishable from editable custom parts. Preserve unrelated working-tree changes.

## Brand Commitments

Compact, practical, restrained. The existing layout is not a constraint: the user requests a cohesive redesign and smoother interaction across board and component editing.

## Evidence on Hand

Current source, example projects, regression tests, and existing desktop/mobile QA captures. Physical fit and fabrication readiness require separate evidence.

## Product Principles

- Maintain project context across editing tasks.
- Make selection, editable properties, and save state clear.
- Consolidate overlapping controls while retaining useful capability.
- Keep detailed technical controls available without crowding the primary workflow.
